# ss_gen — original practice-problem generator + sandbox grader

Why this exists: the public StrataScratch MCP only exposes a small **freemium**
pool (~29 Easy, ~33 Medium, a handful of Hard), even on a Premium account. At
5 problems/day the Medium pool is exhausted in ~8 days, so the daily scheduler
is forced to repeat. This toolkit generates **unlimited original problems** with
synthetic, reproducible data and **grades your solution in the Cowork sandbox** —
independent of the freemium ceiling.

Trade-offs to know (kept honest):
- Problems are generated by templates, not authored by StrataScratch — difficulty
  calibration is approximate.
- Grading is this repo's comparison logic (values, order-insensitive unless the
  problem says otherwise), not StrataScratch's official checker.
- You solve here (SQL or pandas), not in the familiar StrataScratch web UI.

## Setup

```bash
pip install duckdb pandas        # one time
```

## Generate a problem

```bash
python ss_gen.py --list                                   # show categories
python ss_gen.py --category window --difficulty medium    # random seed
python ss_gen.py --category date --difficulty hard --seed 7   # reproducible
```

Categories: `aggregation`, `window`, `join`, `date`, `string`, `filter`.
Difficulties: `easy`, `medium`, `hard` (larger/twistier tables).

Output lands in `problems/<problem_id>/`:
- `problem.json` — statement, schema, reference SQL, expected output
- `<table>.csv` — one file per synthetic table

The same `--category/--difficulty/--seed` always reproduces the same problem.

## Solve, then grade

Write a solution file and check it:

```bash
# SQL (DuckDB / PostgreSQL-ish dialect)
python grade.py problems/gen-window-medium-0007/problem.json mysol.sql

# pandas — your code must assign the final DataFrame to `result`
python grade.py problems/gen-window-medium-0007/problem.json mysol.py
```

Each table is preloaded by name. Example pandas solution:

```python
m = employee.groupby('department')['salary'].transform('max')
result = employee[employee['salary'] == m][['department', 'first_name', 'salary']]
```

Grader output is `✓ PASS` or `✗ FAIL` with a row-level diff (missing / extra rows)
and the reference SQL when you miss.

## How it fits the daily routine

Use it to **top up** days when fresh freemium Mediums run out, or to drill a single
weak category (e.g. `--category window`) as many times as you like. PySpark grading
is not in this v1 (SQL + pandas only); add it later if useful.
