# Data Coding Routine
Ongoing practice repository for practical coding skills for **Data Analyst / Data Engineer** roles.
Focus areas: **SQL (analytics patterns)**, **Python (Pandas/Polars)**, and **PySpark (DataFrame + Spark SQL)**.

## What you'll find
- **SQL**: joins, CTEs, window functions, time-series, cohort/KPI logic
- **Python**: data manipulation, validation, reusable utilities. Focus on readability, correctness, and reusability
- **PySpark**: scalable transformations using Spark SQL & DataFrame API

## Repository structure
```
├─ sql/        # Analytical SQL solutions by difficulty and pattern
├─ python/     # Pandas / Polars implementations
├─ pyspark/    # Spark DataFrame & Spark SQL solutions
└─ docs/       # Setup notes and common analytical patterns
```

## Conventions
Each solution file includes:
- Problem summary (written in own words)
- Difficulty level
- Source link (problem platform)
- Key concepts used (e.g. window functions)

Problem statements and datasets are not copied to avoid duplication or licensing issues.
